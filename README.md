# InesPNJ

Site d'InesPNJ : liens réseaux, bouton de don, FAQ, setup, derniers TikTok et
récap des événements passés (Make-A-Wish · Avril 2026).

**Stack** : Next.js 14 (App Router) · TypeScript · Tailwind CSS · Vercel.

Aucune base de données ni variable d'environnement n'est nécessaire.

## Lancer en local

```bash
npm install
npm run dev
```

http://localhost:3000

## Déployer

Vercel → importe `mindyourbiz9000/ines-makeawish` → **Deploy**.
